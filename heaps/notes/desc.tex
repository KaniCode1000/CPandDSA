	\section{Median Maintenance}
	\textbf{Question:} Given a sequence of numbers, present the median of the numbers every time a new number is given. \newline
	
	\textbf{Solution:} Keep a Min Heap $H_1$ and a Max Heap $H_2$, keep both the heaps balanced, i.e having equal number of elements for $2k$ elements and for odd iteration $(2k+1)$, a discrepancy of $1$.  \newline
	
	Idea is that the maximum element of $H_2$ and/or minimum element of $H_1$ will be the median. Therefore, for $i^{th}$ iteration, insert the element based on comparision with the previous median. To keep the balancing property, only edge case is that of a new element coming in at $2k+1$ elements total. Here, one heap might have $k+1$ and other $k-1$ elements. So, just extract min/max based on the heap type and insert it into the other heap. \newline
	
	\textbf{Runtime:} $O(log \, i)$ for each $i^{th}$ iteration, since a constant number of heap operations are being done every iteration.
